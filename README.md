🔗 Live Demo: https://mediconnect-punjab.vercel.app

A modern, responsive healthcare web platform designed to help residents of Punjab easily discover nearby doctors, view verified profiles, and book appointments in real time. The platform reduces healthcare access delays by centralizing doctor discovery and scheduling into a single intuitive system.

🚨 Problem Statement

Finding the right specialist in Punjab is often time-consuming due to fragmented and offline systems. Patients struggle with:

Lack of centralized doctor listings
Difficulty in verifying doctor credentials
No real-time appointment visibility
Delayed access to medical care

💡 Solution

MediConnect Punjab provides a single digital healthcare hub that enables:

Easy discovery of nearby doctors via an interactive map
Transparent doctor profiles with verified information
Real-time appointment booking and management
Secure user dashboard for patients

✨ Key Features
🗺️ Smart Doctor Discovery

Interactive Google Maps integration to locate doctors across Punjab based on specialization and location.

👨‍⚕️ Verified Doctor Profiles

Detailed profiles including:

Specialization
Experience
Availability
Consultation details

📅 Real-Time Appointment Booking

Users can view live availability and book or modify appointments instantly.

🔐 Secure Authentication System

User login system ensuring safe access to personal dashboards and appointment history.

📊 Personalized Patient Dashboard

Patients can manage:

Upcoming appointments
Booking history
Profile details

🛠️ Tech Stack
Frontend: HTML5, CSS3 (Glassmorphism UI), JavaScript (ES6+), Bootstrap
Mapping API: Google Maps API
Backend/Data Layer: JSON-based integration / SQL Database
Hosting: Vercel

🎯 Impact
Improves healthcare accessibility in semi-urban and rural areas
Reduces time spent searching for specialists
Enhances transparency in doctor selection
Provides a digital-first healthcare experience

AI-based doctor recommendation system
